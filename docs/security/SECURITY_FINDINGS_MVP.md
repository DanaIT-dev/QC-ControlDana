Контроль — lockfile и повторный audit. Semgrep также просит `blockExoticSubdeps` и `trustPolicy`; их включение требует обновления lockfile metadata и не входит в этот image-hardening. | CVE-2026-45447                                                               | FIXED                       | Это дефект `PKCS7_verify()` в OpenSSL, не уязвимость Redis. Повторный Trivy image scan не находит этот CVE ни в одном production-образе. Закреплённый `redis:7-alpine` содержит `libssl3` и `libcrypto3` `3.3.7-r1`. Postgres — OpenSSL `3.5.7-1~deb13u2`, Caddy — `libssl3` `3.5.8-r0`. API/migrator получают OpenSSL `3.0.22-1~deb12u1`, потому что `ca-certificates` тянет `libssl3`; Trivy этот CVE на них не ставит. Закрытый порт не является исправлением и здесь не используется как основание. |

Встроенный в Node `24.21.0` undici — `7.29.1`. Копии `undici@6.27.0` и `brace-expansion@5.0.7` принадлежат CLI `npm` и удаляются из final stage API, web и migrator.                                                                                                                                                                                                                                                                     |

Исправленный пакет `3.5.7-1~deb13u2` в закреплённом образе ещё отсутствует; после нового официального digest scan повторяется. Закрытый порт не является причиной.                                                                                                                                                                           |
