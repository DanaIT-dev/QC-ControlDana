# Разбор известных security findings

Классификация относится к текущему дереву. «Уже было» не используется вместо статуса.

| Finding                                                                      | Статус                      | Основание                                                                                                                                                                                                    |
| ---------------------------------------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `.npmrc` `minimumReleaseAge` отсутствует, в workspace `minimumReleaseAge: 0` | ACCEPTED WITH JUSTIFICATION | Жёсткий возраст релиза блокировал актуальные AWS SDK и `prisma@7.10.0`. Контроль — lockfile и повторный audit. Blanket-ignore сканеров не добавлен.                                                          |
| `pnpm-workspace.yaml` `allowBuilds` для prisma, esbuild, argon2              | ACCEPTED WITH JUSTIFICATION | Это разрешение сборки нативных postinstall, не отключение audit. Пакеты нужны runtime.                                                                                                                       |
| Semgrep на `<script>` в тесте act-chat                                       | NOT APPLICABLE              | Строка находится в тестовом payload, не в HTML продукта.                                                                                                                                                     |
| Semgrep `x-frame-options-misconfiguration`                                   | NOT APPLICABLE              | Значение заголовка — литерал `DENY`. CSP содержит `frame-ancestors 'none'`.                                                                                                                                  |
| Semgrep `gcm-no-tag-length` в backup archive                                 | FIXED                       | Шифрование backup передаёт `authTagLength: 16` в AES-256-GCM.                                                                                                                                                |
| HIGH `image-size`                                                            | FIXED                       | Runtime обновлён до 2.0.4.                                                                                                                                                                                   |
| HIGH `nodemailer`                                                            | FIXED                       | Runtime обновлён до 9.1.1.                                                                                                                                                                                   |
| HIGH `fast-uri`                                                              | FIXED                       | Override в `pnpm-workspace.yaml`: 3.1.8 и 4.1.5.                                                                                                                                                             |
| HIGH `sharp`                                                                 | FIXED                       | Override `0.35.5` для зависимости Next.js.                                                                                                                                                                   |
| HIGH `deepmerge-ts` через Prisma CLI                                         | ACCEPTED WITH JUSTIFICATION | Не достижим из HTTP-обработчиков. Исправление находится в Prisma 8, который ещё release candidate. Пересмотр: 2026-12-01.                                                                                    |
| HIGH `mysql2` через Prisma CLI                                               | NOT APPLICABLE              | Не импортируется API и worker на пути запроса.                                                                                                                                                               |
| Trivy DS026 на Dockerfile                                                    | FIXED                       | В образы API и web добавлен HEALTHCHECK.                                                                                                                                                                     |
| OS CVE образов postgres, minio, clamav, mailpit и redis                      | ACCEPTED WITH JUSTIFICATION | Это CVE базовых образов. Production не публикует их порты. У части CVE нет исправленной версии. Redis `7-alpine` локально содержит CVE-2026-45447; digest образа фиксируется на хосте перед первым запуском. |
| Redis ACL и отсутствие `requirepass` в argv                                  | FIXED                       | Production compose использует secret files и ACL entrypoint, порт Redis не публикуется.                                                                                                                      |

Повторный `pnpm audit --prod` после обновлений: critical 0, high 2 (`deepmerge-ts`, `mysql2`). База Trivy скачана. Gitleaks по рабочему дереву и истории: утечек нет. Semgrep после исправления GCM больше не должен сообщать `gcm-no-tag-length`.
