# Приёмка MVP

Этот лист заполняют живые представители ролей. Автоматические Playwright-тесты не ставят PASS и не заменяют подпись.

Роли: ADMIN, MANAGER, SGR_MANAGER, RESPONSIBLE_ENGINEER, CONTRACTOR_ENGINEER, SUPER_ADMIN, PENDING_ROLE.

Для каждого сценария ниже графа «Фактический результат», «PASS/FAIL», «ФИО», «Дата» и «Комментарий» остаётся пустой, пока человек не прошёл сценарий на стенде.
